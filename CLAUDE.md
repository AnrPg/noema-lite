# noema-lite — notes for Claude and other code agents

**Language courses (🌍):** before you change anything under `library/languages/`, `engine/lang*`, `engine/langcore.js`,
`tools/*lang*`, `tools/lang_sources/`, `tests/lang*` or `docs/LANGUAGES.md`, read **`docs/LANGUAGE_RULES.md`** — the
binding rules for every agent (decisions D1–D19: the common order of all language paths, catalogues of phenomena, the
facade of every word, every meaning a concept, no built-in point of view, the open-ended course). Briefs you write for
other agents start with `tools/lang_sources/AGENT_BRIEF.md`. A plan change goes into `docs/LANGUAGES.md` and
`docs/LANGUAGE_RULES.md` first; `tests/lang_rules.py` checks they agree.

Everything else: see `README.md` (layout, commands) and the docs it links.
